# 📘 Student Management Application

A simple *Student Management Application* built using *Node.js* and *Express.js*.  
This project demonstrates basic *CRUD operations* (Create, Read, Update, Delete) for managing student records.


## 🚀 Features
- Add new students
- View all students
- View student by ID
- Update student details
- Delete student records
- RESTful API structure



## 🛠️ Technologies Used
- Node.js
- Express.js
- Body-parser
- Nodemon
- Git & GitHub
